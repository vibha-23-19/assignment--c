1.Write a program that prints the numbers from 10 down to 1 using a for loop, similar to a countdown timer.

#include <stdio.h>
int main() 
{
    for (int i = 10; i >= 1; i--) {
        printf("%d\n", i);
    }
    return 0;
}

2.Create a menu-driven console app that lets the user: 1) View your favorite 3 IPL teams, 2) Add a new team, 3) Exit.
 Use a while loop to keep showing the menu until the user chooses Exit.
<br><br><em><strong>Hint:</strong> Use input() (or Scanner in Java) to get the user's choice each time.</em>

#include <stdio.h>
#include <string.h>

int main() {
    char teams[10][50] = {"Mumbai Indians", "Chennai Super Kings", "Royal Challengers Bangalore"};
    int teamCount = 3;
    int choice;

    while (1) {
        printf("\n--- MENU ---\n");
        printf("1) View favorite IPL teams\n");
        printf("2) Add a new team\n");
        printf("3) Exit\n");
        printf("Enter your choice: ");
        scanf("%d", &choice);

        if (choice == 1) {
            printf("\nYour favorite IPL teams:\n");
            for (int i = 0; i < teamCount; i++) {
                printf("%d. %s\n", i + 1, teams[i]);
            }
        } else if (choice == 2) {
            if (teamCount < 10) {
                printf("Enter new team name: ");
                scanf(" %s\n", teams[teamCount]);
                teamCount++;
                printf("Team added!\n");
            } else {
                printf("Team list is full!\n");
            }
        } else if (choice == 3) {
            printf("Exit!\n");
            break;
        } else {
            printf("Invalid choice, try again.\n");
        }
    }

    return 0;
}

4.Explain with your own example the difference between entry-controlled and exit-controlled loops by writing a short code snippet 
for each (for/while vs do-while) and describing what happens if the loop condition is false at the start
 
Entry-controlled loop -> (for/while) checks the condition before running the loop body. 
                         If the condition is false at the start, the body never executes at all.
						 
	#include <stdio.h>

    int main() {
    int a = 10; 

    while (a< 5) {
        printf("%d\n", a);
        a++;
    }
    printf("the loop never executed, not even once.\n");
    return 0;
}
Explaination -> While loop skipped entirely because condition was false.


Exit-controlled  loop -> (do-while)checks the condition after running the loop body. This guarantees the body runs at least once, 
                          even if the condition is false from the very beginning.
  #include <stdio.h>

  int main() {
    int a = 10;
    do {
        printf("%d\n", a);
        a++;
    } while (a < 5);
    printf("the loop still ran once before the condition was checked.\n");

    return 0;
}
Explaination ->  This prints exactly once, even though condition is false Do-while loop ran once before checking the condition.
